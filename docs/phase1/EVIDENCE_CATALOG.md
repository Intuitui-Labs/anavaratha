Owner: Anavaratha Lead · For: Chief of Staff

## Purpose

Name what would count as evidence for the ranked questions — and what does not count yet — without inventing sites, partners, datasets, or readiness.

## What counts (evidence classes)

| Class | What it is | Serves questions | Notes |
|-------|------------|------------------|-------|
| **A. Material-flow accounts** | Documented paths of a material or stock through use → residual → return/loss (mass, volume, or count over time). | Q2, Q4 | Prefer existing public stats, permits, facility reports over new surveys. |
| **B. Institutional documents** | Charters, budgets, SOPs, turnover records, maintenance logs, policy circulars that show how capability is stored or lost. | Q3, Q1 | Attribution + date required. |
| **C. Spatial layers** | Maps or GIS layers that locate stocks, buffers, infrastructure, or land-cover change with method notes. | Q4, Q6 | Method reuse from `lk-edu-geo` patterns only if a spatial Q survives; not domain proof by itself. |
| **D. Structured interviews / oral histories** | Recorded accounts of how people move, teach, or lose operational skill across sites. | Q5, Q3 | Ethics + geography gated by Naveen; none scheduled. |
| **E. Field observation notes** | Dated, located notes on use, residuals, buffers, or institutional practice. | Q1–Q6 | Fieldwork gated; catalog lists the *form*, not a site list. |
| **F. Secondary synthesis** | Peer literature or official reports that define pressure types or regeneration mechanisms for Sri Lanka–relevant systems. | Q1, Q6, Q7 | Cite; do not launder as primary observation. |
| **G. Negative evidence / kill logs** | Explicit records of questions or hypotheses rejected and why. | Q7, Q8 | Required for stage integrity. |

## What does not count yet

| Non-evidence | Why |
|--------------|-----|
| Studio brochure / living-doc premise alone | Orientation, not observation. |
| Unsourced statistics or viral anecdotes | No traceable method. |
| Invented partner MOUs or “quiet conversations” | Gate-locked; fabricating breaks mandate. |
| Product mockups, apps, dashboards | Wrong stage. |
| Market-sizing or venture theses | Peace Valley territory unless boundary lock says otherwise. |
| Education-delivery metrics (attendance, lesson plans) | EdLove/Gurudevi adjacency. |
| A single site anecdote without residual/use structure | Insufficient for capability-cycle claims. |
| Repo existence (`lk-edu-geo`, etc.) | Tooling adjacency ≠ Anavaratha evidence. |

## Mapping to ranked questions (minimum evidence, not a collection plan)

| Q | Minimum to keep the question alive | Enough to *kill* or narrow it |
|---|------------------------------------|-------------------------------|
| Q1 Pressure types | ≥2 independent secondary sources + 1 institutional or material trace naming the same pressure class | Pressure class never appears outside brochure language |
| Q2 Residuals regenerate vs trap | ≥1 material or institutional cycle with residual fate documented both ways (or clear absence of regen path) | Residuals only moralized, never observed |
| Q3 Institutional memory | Turnover or maintenance record showing capability loss/retention | Pure org charts with no operational residue |
| Q4 Material-flow visibility | Proof a cycle is *legible* from existing public/accessible records | Requires building new national data infra first → park or kill |
| Q5 People as carriers | Migration/apprenticeship/churn accounts tied to capability move | Labor stats with no capability content |
| Q6 Ecosystem buffers | Spatial or ecological secondary + one observable buffer under named pressure | Buffer talk with no pressure linkage |
| Q7 Stage-exit sufficiency | This catalog + kill log + boundary memo filled | Circular: “we feel ready” |
| Q8 Constellation test | Written assignment of each live Q to Anavaratha vs sibling tracks | Double-counting with Peace Valley / EdLove / Agri |
