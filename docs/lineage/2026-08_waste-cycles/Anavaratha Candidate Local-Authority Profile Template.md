# Anavaratha Candidate Local-Authority Profile Template

## Purpose

Each candidate should be described using the same structure before any pilot is selected. The profile is a hypothesis document, not a final diagnosis.

## Profile fields

| Field | Required question |
|---|---|
| Candidate identity | What local authority, district, province, or connected system is being described? |
| Spatial boundary | What is inside and outside the profile? |
| Population/activity | What population, households, establishments, markets, visitors, or land area create pressure? |
| Waste streams | Which materials and waste categories are documented? |
| Generation | What is reported, measured, estimated, or unknown? |
| Collection | Who collects, where, how often, with what coverage and equipment? |
| Recovery | What formal and informal recovery pathways are visible? |
| Treatment | What composting, processing, thermal, or other treatment exists? |
| Disposal | Where do controlled and uncontrolled residuals go? |
| Accumulation | Which stocks or hotspots persist, and over what period? |
| Capacity | What physical, operational, financial, human, technical, institutional, political, social, market, and informational capacities exist? |
| Constraints | Which constraints are documented, and which appear binding? |
| Spatial transfer | Where are burden, cost, risk, or material value transferred? |
| Time pattern | What is known about seasonality, project duration, policy change, and persistence? |
| Perspectives | Which generators, workers, operators, authorities, markets, communities, and ecological receptors are represented or missing? |
| Evidence quality | What is direct, reported, estimated, proxy, contested, or unknown? |
| Validation priority | What future observation would most change the diagnosis or decision? |

## Comparison rules

Candidate profiles should be compared only on compatible dimensions. Absolute waste quantities should be paired with appropriate denominators. Nominal capacity should be separated from usable capacity. A policy target should be separated from an achieved outcome. A facility should be assessed as a node in a pathway, not as proof of successful management. A clean public space should not be interpreted as evidence that the total burden has disappeared.

## Candidate profile decision categories

Use the following categories instead of an overall “good/bad” score:

- **Evidence-rich:** enough compatible records exist to construct a provisional flow profile.
- **Evidence-fragmented:** important records exist but cannot yet be reconciled.
- **Institutionally promising:** likely access or cooperation exists, but system evidence is incomplete.
- **Operationally significant:** visible or documented pathway pressure makes the candidate decision-relevant.
- **Validation-ready:** a small set of future observations could test consequential hypotheses.
- **Not yet suitable:** boundary, access, or data quality is too weak for responsible comparison.

A candidate may belong to several categories at once. Selection should favor a place that is both operationally significant and validation-ready, not merely a place with the highest reported waste quantity.
