# Anavaratha Top-Down Descent Architecture

## Why the architecture is changing

The previous sequence moved too quickly from a general waste framework to candidate localities. That risks allowing the characteristics of a selected place to define the model before the model has been properly developed. Anavaratha should instead descend from the largest conceptual scale to the smallest empirical scale.

The project must first ask **what waste is, how waste systems work in general, what dimensions are necessary to understand them, and how those dimensions interact**. Only after the general model is coherent should it be applied to Sri Lanka, and only after the national application is coherent should individual localities be selected.

## The eagle-view descent

| Level | Object of analysis | Completion question | Locality status |
|---|---|---|---|
| 1. Ontology | Waste, material cycles, flows, stocks, residues, value, burden | What exactly is the phenomenon we are studying? | No locality |
| 2. General system | Waste as a socio-ecological, economic, political, and infrastructural system | What are the universal components and relationships? | No locality |
| 3. Analytical dimensions | Material, population, activity, capacity, constraint, actor, power, time, space, ecology, and evidence | Which dimensions are needed to explain variation? | No locality |
| 4. Waste streams | Organics, plastics, paper, metals, glass, textiles, e-waste, construction waste, hazardous waste, wastewater, and residuals | How does each stream differ in generation, value, risk, and pathway? | No locality |
| 5. General failure theory | Why systems fail, persist, adapt, or transfer burdens | What mechanisms recur across places and contexts? | No locality |
| 6. Country architecture | Sri Lanka’s material inflows, institutions, laws, policies, markets, infrastructure, and environmental receptors | How does the general model appear nationally? | Country-wide only |
| 7. National variation | Provinces, districts, urban/rural forms, density, land, climate, economic activity, and institutional capacity | What kinds of system variation exist inside Sri Lanka? | Regional categories, not selected cases |
| 8. Comparative typology | Facility-linked, dense urban, coastal, small-authority, rural, tourism, industrial, agricultural, and crisis contexts | Which system types should be compared? | Abstract types or broad groups |
| 9. Controlled local descent | A locality selected because it tests a specific type or hypothesis | Which place can most effectively test the model? | Locality only here |
| 10. Field validation | Targeted observations and measurements | Does the model explain the selected system in practice? | Field site |

## Non-negotiable descent gates

A layer is not complete because sources have been collected. It is complete when its concepts, variables, mechanisms, evidence requirements, and uncertainties are clear enough to support the next layer.

| Gate | Requirement before descending |
|---|---|
| Conceptual gate | Terms and boundaries are defined without relying on a particular place |
| Relational gate | The main relationships between pressure, capacity, pathways, stocks, and outcomes are stated |
| Measurement gate | Each important concept has possible indicators and known limitations |
| Variation gate | The model explains why the same mechanism could differ by scale, population, space, or time |
| Evidence gate | Existing knowledge is separated into observed, estimated, interpreted, contested, and unknown |
| Typology gate | Candidate contexts are classified by system type before named localities are discussed |
| Selection gate | A locality is chosen only because it is a useful test of a prior hypothesis |

## What changes immediately

The named candidates—Colombo, Dehiwala–Mt. Lavinia, and Dompe/Gampaha—should be temporarily moved into a **deferred application register**. They remain possible future tests but must not organize the current theory-building or evidence review.

The next work should therefore explore waste as a general phenomenon, then build the Sri Lankan national architecture, then distinguish waste-stream cycles, capacities and constraints, time-space effects, and system types. The project should not ask “Which location first?” until it can answer “Which type of system do we need to understand, and why?”

## Governing principle

> **Anavaratha descends only when the current layer can explain the next layer without being defined by it.**

This preserves the eagle-view perspective while still allowing eventual local specificity and field relevance.
