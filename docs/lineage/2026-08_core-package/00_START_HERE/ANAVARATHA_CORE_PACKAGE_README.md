# Anavaratha Core Package

**Version:** 0.1  
**Date:** 25 August 2026  
**Geography:** Sri Lanka

## Purpose

This is the lean conceptual and research package for Anavaratha. It contains the principal project identity, three-domain architecture, thermodynamic frame, research descent methodology, waste-system concepts, divergent directions, practical leverage, and synthesized findings.

It deliberately excludes raw datasets, GIS layers, source PDFs, spreadsheets, charts, extraction text, intermediate scripts, and detailed machine-readable registers. Those materials remain in the full evidence archive:

`ANAVARATHA_PROJECT_PACKAGE_V0_1.zip`

## Included domains

1. **Freedom from Waste** — reducing unmanaged residual burdens, exposure, leakage, accumulation, unsafe work, and institutional abandonment.
2. **Material Afterlives** — understanding latent utility, reuse, repair, exchange, refurbishment, salvage, and post-use circulation.
3. **Ecological Flourishing** — studying ecological capability, regeneration, restoration, biodiversity, trees, forests, wetlands, waterways, soils, and stewardship.

The three domains are connected but analytically distinct. Waste reduction is not automatically reuse, reuse is not automatically ecological benefit, and ecological activity is not automatically flourishing.

## Excluded materials

The following are intentionally not included in this lean package: raw and derived CSV files; GeoJSON, Shapefile, and other GIS layers; source PDFs and DOCX files; charts and images; extracted OCR or PDF text; Python and shell scripts; machine-readable audit registers; and the chronological research log.

The exclusions are not deletions. They prevent the Core Package from becoming a large evidence archive and preserve a clear distinction between Anavaratha’s ideas and the supporting research apparatus.

## Core principle

> **Anavaratha studies how materials, institutions, people, and ecosystems preserve or lose capability through cycles of use, disuse, circulation, transformation, residuality, and regeneration.**

The core project sequence is:

> **make visible → define the boundary → distinguish capacity from outcome → trace the middle and residual → identify power and receivers → test leverage → verify persistence.**
