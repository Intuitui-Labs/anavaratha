# Anavaratha

## Source-extraction schema and cross-link rules

**Sri Lanka regenerative-cultivation dimension — Working schema, Version 0.1**

## 1. Purpose

This schema converts existing sources into traceable evidence records for Anavaratha’s living-sector atlas. It separates what a source explicitly states from what Anavaratha infers, proposes, or still needs to verify.

> **Every atlas claim must be traceable to a source, a place, a time, a method, and a stated level of confidence.**

## 2. Evidence record

| Field | Required content |
|---|---|
| **Evidence ID** | Unique identifier |
| **Source ID** | Link to the source-map entry |
| **Exact source title** | Title as published or displayed by the holder |
| **Institution or author** | Original holder, author, agency, community, or research group |
| **Claim** | One specific statement supported by the source |
| **Claim type** | Identity, distribution, status, habitat, function, relationship, season, stewardship, policy, method, or gap |
| **Geography** | Site, district, watershed, ecological region, national, or other |
| **Scale** | Organism, plot, habitat, corridor, basin, regional, national, or global |
| **Time** | Publication date, observation period, historical period, or update date |
| **Method** | Survey, inventory, interview, experiment, remote sensing, policy review, observation, or other |
| **Direct or inferred** | Directly stated by source, or interpretation made by Anavaratha |
| **Confidence** | High, moderate, low, or unknown |
| **Limitation** | Scope, age, method, geography, taxonomy, missing data, or access constraint |
| **Atlas record** | Living-sector record or relationship to which the evidence belongs |
| **Related records** | Other organisms, habitats, relationships, or conditions linked by the evidence |
| **Reuse condition** | Licence, attribution, permission, consent, sensitive location, or other |
| **Next action** | Cite, cross-check, extract, request, map, interview, or leave as gap |

## 3. Evidence-language rules

The extraction layer should use disciplined language:

| Evidence state | Preferred wording |
|---|---|
| **Direct** | “The source reports…” or “The study recorded…” |
| **Supported interpretation** | “This suggests…” or “This can support an inquiry into…” |
| **Unverified lead** | “A possible lead is…” or “This requires verification…” |
| **Missing information** | “The source does not establish…” |
| **Conflict** | “Sources differ on…” |
| **Out of scope** | “Relevant institutionally, but outside the present living-sector focus…” |

The project should not turn a source’s general statement into a site-specific claim, a historical number into a current number, or a project objective into a demonstrated outcome.

## 4. Cross-link types

| Cross-link | Meaning | Example |
|---|---|---|
| **Identity** | Same organism, habitat, or institution under different names | Sinhala name ↔ Tamil name ↔ scientific name |
| **Spatial** | Same place or overlapping geography | Wetland directory ↔ watershed study |
| **Temporal** | Same subject across different dates | Historical checklist ↔ current assessment |
| **Functional** | Different sources describe related ecological functions | Tree shade ↔ soil moisture ↔ pollinator habitat |
| **Relational** | Sources describe interacting beings or systems | Fruiting tree ↔ bird or bat disperser |
| **Institutional** | Different organisations hold complementary responsibility | Forest Department ↔ DWC ↔ CEA |
| **Methodological** | Same question studied through different methods | Remote sensing ↔ field inventory ↔ community observation |
| **Scale** | Evidence moves from organism to habitat to landscape | Species record ↔ corridor ↔ basin |
| **Uncertainty** | One source reveals a gap or challenges another | Catalogue record ↔ missing local confirmation |

## 5. Claim-to-atlas rule

An evidence record may be linked to an atlas record only if the relationship between the claim and the atlas record is explicit. A source about a tree’s identity may support the identity field but not automatically its shade, water, medicinal, or biodiversity functions. A source about a protected area may support legal or habitat context but not automatically prove species recovery.

## 6. Quality and completeness check

Before an extracted record is marked atlas-ready, ask:

| Check | Requirement |
|---|---|
| **Traceability** | Can another researcher find the original source? |
| **Specificity** | Is the claim narrow enough to verify? |
| **Place** | Is the geography stated? |
| **Time** | Is the date or period stated? |
| **Method** | Is the way the information was produced known? |
| **Scope** | Is the claim not larger than the source? |
| **Uncertainty** | Are missing or weak elements visible? |
| **Ethics** | Are licence, consent, privacy, and sensitive locations handled? |
| **Cross-check** | Has a relevant second source been identified where necessary? |
| **Actionability** | Is there a clear next action? |

## 7. Source-extraction outputs

The first pass should produce an evidence register, a source-to-atlas crosswalk, an institutional responsibility map, a catalogue-coverage matrix, an access and reuse register, and a gap map. The aim is a connected research infrastructure rather than a new standalone catalogue.

> **Extract first, interpret second, connect third, and recommend only when the evidence and conditions permit.**
